# pdfViewer

A small, fast PDF viewer that runs entirely in the browser. Files are read locally and never uploaded.

**[Try it →](https://tylerkirk1.github.io/pdfViewer/)** (there's a sample document on the start screen)

Built with React, TypeScript and [PDF.js](https://mozilla.github.io/pdf.js/).

## Features

- Continuous scroll or one page at a time, with pages rendered lazily as you scroll
- Zoom: Auto, Fit page, Fit width, or fixed levels; Ctrl + scroll / pinch to zoom
- Selectable text, working links, and form fields
- Search with highlighted matches, a results list, and Enter / Shift+Enter to step through them
- Sidebar with page thumbnails and the document outline
- Rotate, light and dark themes (follows your system by default)
- Works on phones: the sidebar becomes a drawer

## Keyboard

| Keys | Action |
| --- | --- |
| ← / → | Previous / next page |
| Home / End | First / last page |
| Ctrl + / Ctrl − | Zoom in / out |
| Ctrl 0 | Reset zoom |
| Ctrl F | Search |
| Ctrl O | Open a file |

Use ⌘ instead of Ctrl on a Mac.

## Development

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # unit + component tests (Vitest)
npm run typecheck
```

`public/sample.pdf` is generated by `npm run sample` (no dependencies, see `scripts/make-sample.mjs`).

## Deploying

```bash
npm run deploy     # builds and publishes dist/ to the gh-pages branch
```

The build uses relative asset paths, so it works from any sub-path.
