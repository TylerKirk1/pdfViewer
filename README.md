# pdfViewer

A small PDF viewer that runs entirely in the browser. Files never leave your machine.

**[Live demo](https://tylerkirk1.github.io/pdfViewer/)**

Continuous or single-page view, zoom and fit modes, search, thumbnails, outline, rotation, and light/dark themes. Built with React, TypeScript and PDF.js.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
npm run deploy   # publish dist/ to GitHub Pages
```
